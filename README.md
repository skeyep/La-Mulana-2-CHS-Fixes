# LA-MULANA 2 官方简中修正

修正官方简体中文的谜题线索、剧情与名称，现有 87 项、110 处文本调整。[查看全部修改](CHANGES.md)（含谜题线索）。

## 下载与安装

1. [下载 Windows 补丁](https://github.com/skeyep/La-Mulana-2-CHS-Fixes/releases/latest)，解压全部文件并关闭游戏。
2. 双击 `Install.cmd`，按提示选择游戏目录；在游戏设置中选择中文。
3. 覆盖升级时直接运行新版本的 `Install.cmd`。检查和还原分别运行 `Support/Check.cmd`、`Support/Restore.cmd`。

适用于 Windows Steam 版 build 9559015。0.1.0 为测试版，长文本排版仍在校对。安装器保留原版备份；游戏目录的 `.lm2chs-fixes/Restore.cmd` 也可独立还原。
