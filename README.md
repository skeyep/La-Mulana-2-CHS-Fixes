# LA-MULANA 2 官方简中修正

修正官方简体中文的谜题线索、剧情与名称，共87项、110处。当前版本 **0.1.1**。[完整修改对照](CHANGES.md)含谜题线索。

## 下载与安装

在 [Release](https://github.com/skeyep/La-Mulana-2-CHS-Fixes/releases/latest) 下载适合的平台包，退出游戏并完整解压。

- **Windows**：双击 `Install.cmd`，按提示安装。检查和还原使用 `Support/Check.cmd`、`Support/Restore.cmd`。
- **Steam Deck／Linux**：在 Steam 游戏属性的兼容性设置中强制 Proton，等待 Windows 版下载，启动一次并退出。在桌面模式的解压目录打开终端，运行 `bash ./Install.sh`。检查和还原使用 `bash ./Support/Check.sh`、`bash ./Support/Restore.sh`。

安装后在游戏设置中选择简体中文。升级时直接运行新版安装入口。游戏目录的 `.lm2chs-fixes` 保留最初原版备份和独立还原入口。

适用于 Windows Steam 版 build9559015（Deck 使用 Proton）。长文本逐页排版及 Steam Deck 真机兼容性待验。
